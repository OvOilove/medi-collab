MediCollab - 智慧医疗协同平台
项目地址：https://github.com/OvOilove/medi-collab

基于 SpringBoot 3 + Spring Cloud Alibaba 的分布式医疗信息化系统，面向医联体场景，
实现跨机构医疗资源协同，包含 4 个微服务 + API 网关，共 52 个 REST API。

技术栈：
Spring Boot 3.2.5、Spring Cloud Gateway、Nacos、OpenFeign、JWT、Redis 7、
MyBatis-Plus、RabbitMQ、Knife4j、MySQL/H2

功能模块：
- 用户认证（JWT + BCrypt，Gateway 全局过滤器）
- 预约挂号（Redis 热度排行 + SETNX 分布式锁）
- 电子病历（SHA-256 审计哈希链防篡改）
- 双向转诊（RabbitMQ 异步通知）

快速启动（Demo 模式，无需 MySQL）：
git clone https://github.com/OvOilove/medi-collab.git
cd medi-collab
start-all.bat
