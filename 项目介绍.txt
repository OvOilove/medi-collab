MediCollab - 智慧医疗协同平台
================================

项目仓库：https://github.com/OvOilove/medi-collab


一、选题背景

本系统面向"医联体"场景，构建跨机构医疗资源协同平台。
解决三个核心痛点：

1. 检查结果互认难 —— 跨机构报告安全共享 + SHA-256 审计哈希链防篡改
2. 转诊靠电话     —— 标准化双向转诊流程 + RabbitMQ 异步通知
3. 热门科室挤兑   —— Redis ZSet 实时热度排行 + 配置中心动态调整阈值


二、技术架构

- 基础框架：Spring Boot 3.2.5
- 微服务：Spring Cloud 2023.0.3 + Alibaba 2023.0.1.0
- 注册/配置中心：Nacos 2.3.2
- API 网关：Spring Cloud Gateway
- 远程调用：OpenFeign + LoadBalancer
- 认证：Spring Security + JWT + BCrypt
- 缓存：Redis 7
- ORM：MyBatis-Plus 3.5.7
- 消息队列：RabbitMQ
- 接口文档：Knife4j / SpringDoc OpenAPI 3.0
- 数据库：MySQL 8.0 / H2 (Demo 模式)


三、微服务拆分

medi-gateway      :8080    API 网关，JWT 全局认证，路由转发
medi-user         :8081    用户与认证服务
medi-appointment  :8082    预约挂号服务（含 Redis 热度排行、分布式锁）
medi-record       :8083    电子病历服务（含 SHA-256 审计哈希链）
medi-referral     :8084    双向转诊服务（含 RabbitMQ 异步通知）


四、接口数量

共 52 个 REST API，覆盖增删改查：
- medi-user：12 个（注册、登录、用户 CRUD、角色管理）
- medi-appointment：14 个（预约、科室、排班、热度排行）
- medi-record：13 个（病历、检查报告、审计链、跨机构分享）
- medi-referral：13 个（转诊申请、审批、拒绝、完成、撤回）


五、演示内容（10 项要点）

1. 接口文档    —— Knife4j 自动生成 52 个 API 文档
2. Redis 缓存  —— 用户缓存、ZSet 热度排行、SETNX 分布式锁
3. 单元测试    —— 24 个测试全部通过（JUnit5 + Mockito）
4. Git 提交    —— 推送到 GitHub 远程仓库
5. 登录认证    —— JWT + BCrypt，Gateway 全局过滤器
6. 注册中心    —— Nacos 服务注册与发现
7. 远程调用    —— OpenFeign（appointment 调用 user 校验患者）
8. API 网关    —— Gateway 统一入口，JWT 认证后路由转发
9. 配置中心    —— Nacos Config 实时刷新，无需重启
10. 开发难点   —— Lombok 兼容、序列化、测试隔离等


六、快速启动

git clone https://github.com/OvOilove/medi-collab.git
cd medi-collab

# 前提：启动 Redis 和 Nacos
# Demo 模式（H2 内存库，无需 MySQL）

mvn -f medi-user/pom.xml spring-boot:run -Dspring-boot.run.profiles=demo
mvn -f medi-appointment/pom.xml spring-boot:run -Dspring-boot.run.profiles=demo
mvn -f medi-record/pom.xml spring-boot:run -Dspring-boot.run.profiles=demo
mvn -f medi-referral/pom.xml spring-boot:run -Dspring-boot.run.profiles=demo
mvn -f medi-gateway/pom.xml spring-boot:run

# 或一键启动：start-all.bat
