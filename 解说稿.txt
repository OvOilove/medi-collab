MediCollab 演示解说稿


【开场】

大家好，我做的是一个基于 SpringBoot 3 的分布式医疗信息化系统，叫 MediCollab 智慧医疗协同平台。

项目采用微服务架构，包含 4 个业务服务和 1 个 API 网关，共 52 个 REST API。
技术栈方面：Spring Boot 3.2.5、Spring Cloud Gateway、Nacos 注册和配置中心、OpenFeign 远程调用、
JWT 认证、Redis 缓存、MyBatis-Plus、RabbitMQ 消息队列。

老师课上教过 Eureka，我选 Nacos 是因为 Eureka 已经停止维护了，Nacos 是它的升级替代品，
目前企业主流方案，而且一个组件同时搞定服务注册和配置中心。


【第1步：登录认证】

首先演示登录认证。密码用 BCrypt 加密存储，验证成功后签发 JWT 令牌。
令牌有效期 7 天，同时缓存到 Redis。可以看到返回了 token、userId 和 role。


【第2步：API网关 - 无Token】

系统用 Spring Cloud Gateway 作为统一入口，配置了全局 JWT 过滤器。
不带 Token 的请求直接被拦截，返回 401 Unauthorized。


【第3步：API网关 - 带Token】

带上 Token 后，Gateway 解析 JWT，提取用户信息，注入到请求头里，然后通过 lb 负载均衡转发到下游服务。
可以看到返回了用户列表，总共 3 个用户。


【第4步：接口文档】

系统共 52 个 API，每个 Controller 的方法都加了 SpringDoc 的注解。
这里展示 4 个 Controller：UserController 12 个接口，AppointmentController 14 个，
RecordController 13 个，ReferralController 13 个，合计 52 个。


【第5步：注册中心】

打开 Nacos Dashboard。课本教的 Eureka 已经停止维护了，Nacos 是它的替代方案，
一个组件同时搞定服务注册和配置中心，目前国内企业主流选择。
可以看到 5 个微服务已经注册到 medicollab 命名空间下，每个都有健康检查和心跳。


【第6.1步：创建科室】

然后演示远程调用。先在 appointment 服务上创建一个科室。


【第6.2步：创建排班】

为这个科室创建一条医生排班记录。


【第6.3步：创建预约】

创建预约的时候，appointment 服务会通过 OpenFeign 声明式调用 user 服务的接口，
校验患者是否存在。服务地址从 Nacos 获取，LoadBalancer 做负载均衡。
可以看到预约创建成功，排队号是 1。


【第7步：Redis】

Redis 在系统中有三种用法。第一，ZSet 实现科室热度排行，每次预约自动递增。
第二，SETNX 实现分布式锁，解决号源并发抢占。
第三，用户信息缓存到 Redis，减少数据库查询。
这里创建了两个额外预约，可以看到热度排行已经更新了。


【第8步：配置中心】

这是 Nacos 的另一个功能——配置中心。通过 API 把每日最大预约数从 100 改成 3。
服务加了 @RefreshScope 注解，不需要重启。
再创建第 4 个预约，被新阈值拦截了，提示"该科室今日预约已满，阈值 3"。
配置实时生效，这就是配置中心的价值。


【第9步：电子病历】

接下来演示业务功能。创建一份电子病历，系统自动生成 SHA-256 审计哈希，
用于后续的防篡改验证。


【第10步：转诊】

提交一条转诊申请，状态是 PENDING 待审批。
转诊通知通过 RabbitMQ 异步发送给目标医院。


【第11步：Git】

项目使用 Git 管理，已推送到 GitHub 远程仓库。


【第12步：单元测试】

运行 24 个单元测试，使用 JUnit5 加 Mockito。覆盖了 4 个服务。
可以看到全部通过，0 个失败，BUILD SUCCESS。


【第13步：开发难点】

开发过程中遇到了几个难点。一个是 Lombok 在高版本 JDK 上不兼容。
一个是 LocalDateTime 的 JSON 序列化需要显式注册 JavaTimeModule。
还有泛型类型推断问题，以及移除 Lombok 后构造器注入丢失的问题。
这几个文件体现了这些难点的解决方案。


【结尾】

以上就是 MediCollab 的全部演示，谢谢。
